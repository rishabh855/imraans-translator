# Imran's Translator 🚌😂
> **"Lost in Translation? Imran has entered the chat."**  
> *From OPADSE to Understandable English, Hindi, and Gujarati.*

A hilarious, visually impressive, mobile-first static parody website inspired by the unique Gujarati-English transliteration announcements sent by a legendary bus coordinator on WhatsApp.

---

## 🚀 Features

- **Google Translate for Imran's Language**:
  - **Normal Translation**: 100% accurate, grammatically clean translation preserving bus numbers, pickup junctions, departure times, and transfer plans in **English**, **Hindi**, and **Gujarati**.
  - **Funny Translation**: Exaggerated, satirical interpretation celebrating Gujarati engineering humor.
  - **Savage Translation**: Tough-love roasts inspired by WhatsApp coordinator culture.
- **Bus Decoder Ticket**:
  - Extracts structured logistics (Date, Pickup stop, Bus fleet number, Departure schedule, Mandatory student reallocations).
  - Styled as a vintage bus boarding pass with perforated edges and barcode.
- **The Official Imran Dictionary**:
  - Searchable glossary of iconic terms (`OPADSE`, `KALE`, `BESWANU`, `TAVRATHI`, `BY-PASS THI`, etc.).
  - Gujarati script, pronunciation guides, and real-life WhatsApp examples.
- **Imran's Hall of Fame 🏆**:
  - The most baffling announcements of all time with confusion ratings out of 10 and persistent localStorage favorites.
- **WhatsApp Sample Feed**:
  - Realistic WhatsApp group mockup. Tap any broadcast to instantly inject and decode it.
- **Web Audio Bus Horn**:
  - Synthesized dual-tone bus horn ("PAAAM-PAAAM!") with zero external audio assets.
- **100% Mobile Friendly**:
  - Bottom navigation dock, thumb-friendly touch targets, responsive cards, and zero horizontal scrolling.
- **100% Static & Local**:
  - Zero backend, zero database, zero external API keys required.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Neo-brutalist / Comic pop aesthetic)
- **Icons**: [Lucide React](https://lucide.dev/)
- **FX**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) & HTML5 Web Audio API

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/rishabh855/imrans-translator.git

# Navigate to project folder
cd "imran translator"

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the decoder.
